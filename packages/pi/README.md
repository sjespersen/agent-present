# @agent-present/pi

**Agent Present for [Pi](https://pi.dev).** Your agent answers with native terminal infographics instead of walls of text. Don't make me read.

```bash
pi install npm:@agent-present/pi
```

- The agent gets a `present` tool plus guidance on when to use it, and when not to.
- Presentations render inline: glance by default, `ctrl+o` to scan, `alt+e` to explore.
- `/present auto | always | off | last | demo | view | raw | act <n>`
- `/present last` converts the previous plain-text answer (compatibility mode).

See the [main README](https://github.com/sjespersen/agent-present#readme).
