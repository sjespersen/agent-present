# Gallery

Generated from [`examples/`](../examples) with `npm run gallery` (renderer screenshots) and `scripts/capture-pi.py` + `npm run pi:screens` (real Pi TUI captures, `pi-*.png`, in Pi's own theme). Plain-text golden renders live in [`text/`](text/) and are checked by the test suite.

| file | shows |
|---|---|
| `repo-review.png` | release review: oversized headline number, stacked test bar, risk matrix, broken blocking path |
| `architecture.png` | layered architecture diagram with bus routing and a trust boundary legend |
| `comparison.png` | three-way trade-off with per-dimension best markers and a pick |
| `debugging.png` | trend with threshold and change-point annotation, causal chain, metrics |
| `research.png` | evidence weight, metrics, options tree, fit checklist |
| `timeline.png` | incident timeline, metric with sparkline, evidence |
| `progress.png` | work-in-progress status |
| `repo-review-{scan,narrow,wide,ascii}.png` | the same document at different depths, widths and character sets |
| `before-after-*.png` | conventional prose answer vs. presentation, same facts |
| `pi-*.png` | inside Pi: glance, scan (`ctrl+o`) and the explorer (`alt+e`) |
| `pi-last.png` | `/present last` converting a real, unedited prose answer (live model) |
