| primitive | use for |
|---|---|
| [`verdict`](primitives/verdict.md) | Conclusions, diagnoses, recommendations and decisions. |
| [`metric`](primitives/metric.md) | One number made visually meaningful: value, scale, trend, delta. |
| [`metrics`](primitives/metrics.md) | A compact group of 2–6 related measures — instead of a row of boxes. |
| [`comparison`](primitives/comparison.md) | Explicit trade-offs between alternatives, with a recommended pick. |
| [`flow`](primitives/flow.md) | Processes, pipelines and causal chains. `status: critical` on an edge draws a broken link. |
| [`architecture`](primitives/architecture.md) | Systems and dependencies, optionally with trust boundaries. |
| [`timeline`](primitives/timeline.md) | Chronology, laid out spatially. Notes hang below their event. |
| [`trend`](primitives/trend.md) | A sequence and how it changes; threshold and annotation are placed on the chart. |
| [`distribution`](primitives/distribution.md) | Comparing quantities. `whole: true` renders parts of one total as a stacked bar. |
| [`risk`](primitives/risk.md) | Risks on an impact × likelihood matrix; severity is derived, not declared. |
| [`hierarchy`](primitives/hierarchy.md) | Trees: ownership, taxonomies, module structure. |
| [`checklist`](primitives/checklist.md) | Items with a completion state; the title shows the tally. |
| [`evidence`](primitives/evidence.md) | A claim, its confidence, and the observations that support (or contradict) it. |
| [`change`](primitives/change.md) | Code change impact: churn per file and risk, with the risk centre marked. |
| [`progress`](primitives/progress.md) | Work in progress. With intent `progress` hosts show it temporarily and replace it with the final result. |
| [`text`](primitives/text.md) | Prose, intentionally constrained: ~240 characters at a glance; longer text collapses. |
